# The screenshots this page needs

Drop each file in beside this README, named exactly as listed. The page picks
them up on its own — nothing in `index.html` needs changing. Until a file is
there, its slot shows a dashed box naming the shot that belongs in it, so you
can see what is still outstanding by opening the page.

## Before you capture anything

**Do not photograph real publishers.** This page is public. The home screen
greets people by name and lists their family's assignments, so a real capture
puts names, families and assignments on the open web — the thing the rest of
this system is built to avoid.

Either sign in as a demo publisher with an invented name and family, or blur
every name before sending the file. It is easier to set up the demo once than
to blur twelve screenshots.

## How to capture

Portrait, on a phone, from the installed app rather than a browser tab — the
browser's own chrome in the picture makes the instructions harder to follow.
Turn on Do Not Disturb first so no banner lands mid-capture.

- iPhone: Side button + Volume up
- Android: Power + Volume down

Roughly 320px wide is all the page displays, so anything from a modern phone is
more than enough. PNG.

## Checking your work

Open `../index.html` in a browser. Every dashed box that has turned into a
screenshot is done; whatever is still dashed is still wanted.
